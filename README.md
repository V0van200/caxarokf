# Рита (caxarokf) — фан-страница

Статический сайт без сборки. GitHub Pages публикует main из корня репозитория.
Сведения, ссылки, тексты о канале и статистика находятся в `data/rita.json`. Числа обновляются вручную; дата среза показывается на странице. Статус LIVE не имитируется. Сгенерированный портрет подписан.

Главные разделы: о Рите, общение и Dota 2, расписание и последний известный эфир, цель канала, поддержка, соцсети, вопросы и ответы.

Деликатный фон Three.js хранится локально в vendor; лицензия рядом. FX отключает анимацию. Учитывается prefers-reduced-motion.

Локально: `python3 -m http.server 8080` и открыть http://localhost:8080. Для загрузки JSON нужен HTTP-сервер.
