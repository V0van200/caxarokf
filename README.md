# Рита — фан-страница

Статический сайт без сборки. GitHub Pages публикует main из корня репозитория.
Все сведения, ссылки и статистика находятся в `data/rita.json`. Числа обновляются вручную; дата среза показывается на странице. LIVE-статус не имитируется. Фотография и официальный логотип не используются.

Локально: `python3 -m http.server 8080` и открыть http://localhost:8080 (для загрузки JSON нужен HTTP-сервер).
