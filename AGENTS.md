# rita-site — правила для агентов (GPT, Claude)

Фан-сайт-визитка стримерши **caxarokf** (репозиторий V0van200/caxarokf) (Рита) — https://www.twitch.tv/caxarokf

- Хостинг: **GitHub Pages**, ветка `main`, корень репозитория. Пуш в `main` = публикация (~1 мин).
- Только статика: HTML, CSS, JS. Без сборки.
- Все данные — в `data/rita.json`. Не выдумывать факты; RimWorld и TFT не подтверждены (`games_unverified`).
- Фото и логотип — только с разрешения Риты; до этого — заглушки. Подпись внизу: «Фан-страница».
- Статус «в эфире» на статичном сайте сам не обновляется — не рисовать постоянный LIVE.
- Тёмная тема, розово-фиолетовая палитра (макет у владельца), отлично на телефоне.
- Коммиты начинать с `[GPT]` или `[Claude]`. `push --force` запрещён. Перед работой — `git pull`.
- Никаких ключей и паролей в репозитории.
